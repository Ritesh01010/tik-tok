TikTok Tap Challenge   

A lightweight, mobile-friendly reaction game built with HTML5, CSS3, and vanilla JavaScript that simulates viral TikTok tapping challenges. Users rapidly click/tap a target to accumulate points within a 10-second timer.  

Technical Implementation:
- Core Mechanics:
  - Event listeners (click/touch) track user inputs  
 
- UI/UX:
  - Responsive Flexbox layout (works on mobile/desktop)  
  - CSS animations (transform, keyframes) for visual feedback  


A minimal project demonstrating event handling, DOM manipulation, and time-based logic in <100 lines of code.
